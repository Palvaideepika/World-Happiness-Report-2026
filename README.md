# World Happiness Report 2026 – Excel Charts

## Project Overview
This project analyzes World Happiness Report 2026 data using Microsoft Excel.

## Charts Created
- Average Life Evaluation
- Top 10 Happiest Countries
- Top 10 Happiest Countries – 2025
- Average Happiness Factors

## Tools Used
- Microsoft Excel
- World Happiness Report 2026 dataset

## Key Insights
- Average life evaluation generally increased from 2011 to 2025.
- Finland ranked first among the happiest countries.
- Log GDP had the highest average explained contribution among the happiness factors.
